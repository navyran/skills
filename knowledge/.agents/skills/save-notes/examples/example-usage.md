### 自动化脚本示例
```bash
#!/bin/bash
# 自动保存每日阅读

ARTICLES=(
  "https://example.com/morning-article"
  "https://example.com/tech-news"
  "https://example.com/inspiration"
)

for url in "${ARTICLES[@]}"; do
  echo "保存: $url"
  node ~/.openclaw/workspace/skills/save-notes/scripts/save-notes.js \
    "$url" \
    "~/每日阅读/$(date +%Y-%m-%d)" \
    "每日阅读"
done
```

## 故障排除示例

### 问题：内容提取失败
```
❌ 无法提取文章内容
🔧 解决方案：
  1. 检查URL是否正确
  2. 尝试手动复制内容
  3. 使用备用提取方法
```

### 问题：保存路径不存在
```
❌ 保存路径不存在：~/不存在的文件夹
🔧 解决方案：
  1. 创建目录：mkdir -p ~/不存在的文件夹
  2. 使用现有目录
  3. 检查权限设置
```

### 问题：Git配置错误
```
❌ Git操作失败：未配置用户信息
🔧 解决方案：
  1. 配置git用户：git config user.email "you@example.com"
  2. 配置git用户名：git config user.name "Your Name"
  3. 检查git仓库初始化
```
